36) سياسة الدفع

200 جنيه.

يدفعه في العيادة.

37) عمولة دلّني

عمولة المنصة:

5% من سعر الكشف الكامل.

وليس 5% من المبلغ المدفوع مقدمًا.

مثال:

سعر الكشف:

400 جنيه.

المقدم:

200 جنيه.

عمولة دلّني:

20 جنيه.

مستحق الطبيب من المبلغ الموجود لدى دلّني:

180 جنيه.

والمريض يدفع للطبيب في العيادة:

200 جنيه.

إجمالي الطبيب:

380 جنيه.

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
